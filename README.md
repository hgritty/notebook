# hgritty's Notebook

Personal knowledge base built with Material for MkDocs.

## Local development

```powershell
pip install -r requirements.txt
mkdocs serve
```

Preview:

```text
http://127.0.0.1:8000/
```

## Build

```powershell
mkdocs build
```

## Deploy

```powershell
mkdocs gh-deploy
```

The public site is:

```text
https://hgritty.github.io/notebook/
```
